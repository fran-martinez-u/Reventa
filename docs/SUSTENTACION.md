# Guía de sustentación

1. Explicar el problema del negocio y los cinco módulos.
2. Mostrar el modelo ER y las siete tablas.
3. Explicar el flujo: HTML → fetch → ruta FastAPI → sesión SQLAlchemy → PostgreSQL → JSON → tabla HTML.
4. Mostrar un CRUD completo, dos búsquedas y los indicadores del resumen.
5. Demostrar roles: administrador, vendedor y revendedor.
6. Crear un pedido y explicar el descuento de stock, el saldo y la cancelación.
7. Mostrar Swagger, una validación y las pruebas automatizadas.
8. Mostrar los reportes y los commits reales de cada integrante.

La aplicación conserva PostgreSQL con la autorización indicada por el estudiante. No afirmar que se utiliza Oracle. Las contraseñas nunca se devuelven por la API; .env no se comparte.
